# College AI Voice Agent

## Overview
An AI-powered voice assistant built using Vapi, OpenAI, Deepgram, and Twilio.

## Features
- Answers student queries
- Handles phone conversations
- Appointment scheduling
- AI-powered responses
- Real-time voice interaction

## Tech Stack
- Vapi
- OpenAI GPT-4o Mini
- Deepgram
- Twilio
- Python
